## 远端 / 共享算力的操作纪律

> 只在碰远端机器、集群或共享 GPU 的项目里 opt-in（`kit add remote-compute`）。
> 具体主机名、IP、账号**不写进这里**——那是个人清单，放私有位置；这条只管**怎么操作**。

- **可达 ≠ ping 得通**：ICMP 通、TCP 22 可能是黑洞。判断可达用真正要走的那条路（`ssh -o ConnectTimeout=10 <alias> true`），
  ⛔ 别拿 ping 当结论。
- **`Permission denied (publickey)` 先查认证，不先查网络**：短期签名证书 / token 过期是最常见原因。
  先看证书有效期（`ssh-keygen -L -f <cert>`）再去排网络。
- **共享队列留余量**：数组作业默认串行（Slurm `--array=…%1`），⛔ 不要一次占满共享节点；
  要并发先确认别人没在用。
- **停机 / 重启 / 关虚拟层之前先查谁依赖它**：关掉一层（VM、WSL、容器运行时）常会连带停掉上面
  正在跑的实验，且不自动恢复。⇒ 先查在跑的进程（`pgrep -af <job>`），写下恢复步骤再动手。
- **有挂载卷的 VM 重启前先按平台要求卸载 / detach**，否则可能卡在启动循环。
- **远端长任务的完成信号**走 `long-task-monitor` 的外部任务配方，⛔ 不自匹配 pgrep。
