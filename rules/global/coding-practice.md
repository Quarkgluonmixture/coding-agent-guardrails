## 编码实践

`work-discipline` 管**怎么干活**（拆分、实测、单一真源、验证方法）；这条只管**代码长什么样**。
每条都反推自一次实盘代价；**案例档案在 `~/claude-kit/references/silent-degradation-cases.md`**，
写兜底 / 探测 / 重试 / 接宿主扩展前，或诊断「日志和页面都正常但结果不对」时去读。

- **⭐ 静默降级比崩溃更贵**：吞掉异常退到兜底路径的 `except` 会让**每一次**调用都悄悄变坏，
  而日志和页面看上去仍然正常——最后发现它的通常不是测试，是用户。
  ⇒ **兜底路径必须 `logger.exception` 大声记录**（⛔ 不是 `debug`），宁可崩也别每次悄悄降级；
  **`except Exception` 只在说得出它捕哪几类时才写**，否则显式列异常。

- **能力探测要探"能不能用"，不是"在不在"**：`command -v` 会命中占位壳。探测就真的调用一次。

- **走宿主的正规入口，不是"能跑的那条分支"**：接入前先 grep 出宿主的**注册表 / 校验函数 /
  发现路径**，按它要的形状注册齐——缺一件就是静默不加载，而拦截点常在你那条分支**之前**，
  改它救不了。⛔ **空字符串不是"未设置"**；⛔ 别拿 A 路径的成功证明 B 路径的配置对。

- **重试与降级的粒度要对准失败的阶段**：先列出流水线各阶段，逐段回答「这里失败了谁接住」
  （只给投递写了队列、生成失败没有 = 一次 DNS 中断丢掉整份产出）。次数和退避上限**一起看**
  （3 次 × 指数退避根本够不到 60 秒那档）。瞬时错误分类器要**窄**（⛔ 别放裸的 `failed`/`error`）。
  **同一状态码下的子码是不同故障类**，⛔ 别按 HTTP 状态码一刀切。
  **补跑必须走和正常完成完全同一条终态持久化路径**。

- **⛔⛔ 写测试前先说出它能抓住哪个 bug —— 说不出就别写。** 实测过：一条能力 8 个产品文件配
  **17 个测试文件**，其中 14 个是冻住的全局计数/清单副本，**零 bug**，只让人把同一份清单重打 6 遍。
  ⇒ ① **正向断结构**（断 `##` → `<h2>`，⛔ 不是断"零外部请求 + 字节数对"）；② 写 `== <当期全局值>` 前
  先问：**我要说的是「我没动它」还是「谁都没动它」？** 前者是**关系式**，后者才是快照，而后者几乎总是错的；
  ③ 基线**逐条对**不看总数；④ **隔离状态根**。⚠️ 只有阈值/预算该**故意**冻——红本身就是产物。

- **改别人的代码：扩展点 > 补丁，配置 > 源码**。别急着硬 fork，**先量一次冲突**。补丁要搬到
  **合并线之外**；⚠️ 未提交的本地补丁会被上游更新器的 `stash -u` + `reset --hard` 吞掉。

- **默认值往安全的方向倒**：副作用**默认关**、显式 flag 才打开；兜底取**最严**那档；
  **fail-closed 要在碰数据之前**（先验身份再碰存储，且只绑 `127.0.0.1`）；
  **缺失优于错误**（抽不出摘要就整个 key 省略，⛔ 不是空字符串——消费端 fallback 才接得住）；
  **不给打不开的门按铃**（推送前先确认这个身份打得开目标页）。

- **文本编码边界**：跨进程的文本一律**显式编码**——`subprocess` 捕获走 bytes + 显式 decode
  （⛔ 不用 `text=True`），JSON/日志写死 `encoding='utf-8'`，Python 项目设 `PYTHONUTF8=1`。
  ⛔ 源码里别粘贴字面零宽/不可见字符，用 `chr()` 构造。细则见
  `~/claude-kit/references/text-encoding-and-cjk.md`。
